# ⚔️ Battle Légendaire

Bienvenue dans **Battle Légendaire** !

Battle Légendaire est un jeu d'aventure et de combat créé par Arie Leib.

## Fonctionnalités

- 🎮 Jouer au jeu
- ⚔️ Combattre des ennemis
- 🎒 Inventaire
- 🛡️ Armures
- 🗡️ Armes
- ⭐ Compétences
- 🛒 Boutique
- ❤️ Barre de vie
- 💰 Pièces et récompenses
- 🐺 Boss et niveaux

## Structure du projet

- `index.html` : page d'accueil
- `home.html` : menu principal
- `play.html` : jeu
- `inventory.html` : inventaire
- `shops.html` : boutique
- `skill.html` : compétences
- `armor.html` : armures
- `weapons.html` : armes
- `game.css` : style du jeu
- `game.js` : logique du jeu
- `main.js` : fonctions générales

## Objectif

Le but est de devenir le plus grand héros de Battle Légendaire, de battre tous les boss, de récupérer des équipements puissants et de terminer tous les niveaux.
